# SecureAccess - Sistema de Controle de Acesso Biométrico

Sistema SaaS completo de controle de acesso com biometria e reconhecimento de voz, integrado a portaria digital para empresas.

## 🚀 Funcionalidades

### Dashboard
- Visão geral em tempo real do sistema
- Estatísticas de acessos (total, presentes agora, biometria, voz)
- Gráficos de acessos por dia da semana
- Fluxo de pessoas por horário
- Distribuição de métodos de acesso
- Últimos acessos registrados com temperatura

### Reconhecimento Biométrico
- Escaneamento de impressão digital
- Feedback visual em tempo real
- Identificação automática com nível de confiança
- Liberação automática de acesso
- Registro automático de logs

### Reconhecimento de Voz
- Captura de amostra de voz
- Análise de padrão vocal
- Comparação com amostras cadastradas
- Identificação com nível de confiança
- Liberação automática de acesso

### Cadastro de Pessoas
- Cadastro completo de funcionários, visitantes e prestadores
- Captura de biometria (impressão digital)
- Captura de amostra de voz
- Informações completas (nome, CPF, email, telefone, cargo, departamento)
- Geração automática de crachá
- Busca e filtros avançados
- Edição e exclusão de cadastros

### Portaria Digital
- Controle remoto de até 3 portas
- Status em tempo real das portas
- Abertura/trancamento remoto
- Interfone para comunicação com portaria externa
- Autorização de visitantes
- Bloqueio de emergência
- Monitoramento de visitantes aguardando

### Logs de Acesso
- Histórico completo de movimentações
- Filtros por método, tipo e data
- Busca por nome ou porta
- Exportação para CSV
- Informações detalhadas (temperatura, observações)
- Estatísticas resumidas

### Relatórios
- Análise detalhada de acessos
- Gráficos por departamento
- Utilização por porta
- Fluxo por horário (24h)
- Métodos de acesso mais utilizados
- Estatísticas de pico e média diária

### Configurações
- Configuração de métodos de autenticação
- Nível de segurança ajustável
- Conexão com dispositivos (portaria, biometria, voz)
- Notificações (email, push)
- Backup automático
- Informações do sistema

### Sistema de Notificações
- Notificações em tempo real
- Alertas de acesso liberado/negado
- Notificações de cadastro
- Alertas de emergência
- Painel de notificações com histórico

## 🎨 Interface

- Design moderno e profissional
- Tema escuro (dark mode)
- Interface responsiva
- Animações suaves
- Feedback visual em todas as ações
- Ícones intuitivos
- Gradientes e efeitos visuais

```bash
# Instalar dependências
npm install

# Executar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview da build
npm run preview
```

## 📱 Uso

### Para Empresas

1. **Cadastro Inicial**
   - Acesse "Cadastro" no menu
   - Registre funcionários com biometria e voz
   - Configure departamentos e cargos

2. **Configuração de Portas**
   - Acesse "Portaria Digital"
   - Configure as portas da empresa
   - Teste o controle remoto

3. **Monitoramento**
   - Use o "Dashboard" para visão geral
   - Acompanhe "Logs de Acesso" para histórico
   - Gere "Relatórios" para análise

4. **Reconhecimento**
   - Acesse "Reconhecimento" para testes
   - Configure os sensores biométricos
   - Teste o reconhecimento de voz

### Para Operadores de Portaria

- Use a "Portaria Digital" para controle diário
- Autorize visitantes manualmente
- Monitore as câmeras em tempo real
- Receba notificações de acessos
